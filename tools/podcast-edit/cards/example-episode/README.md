# Example episode folder for the card tools

EXAMPLE DATA, NOT MEASUREMENTS. The CSV files in `raw/` only show the format; the real raw data of an episode stays outside this public repo and is reached through `cards/roots.json` aliases.

```sh
bun tools/podcast-edit/cards/cards.ts check tools/podcast-edit/cards/example-episode
bun tools/podcast-edit/cheatsheet.ts tools/podcast-edit/cards/example-episode
```
